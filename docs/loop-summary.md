## 9. השערים — מה חוסם מה

**`scripts/hooks/pre-push`** — רץ בכל דחיפה, בסדר הזה:
```
1. בעלות ענף      ⇒ מי אתה, ולאן מותר לך (טבלה בסעיף 4)
2. שער הנעילה     ⇒ נעילה זרה חיה ⇒ ⛔ אין קוד (רגיסטר מותר)
3. שלמות רגיסטר   ⇒ רץ **גם** תחת SKIP_VERIFY
4. verify         ⇒ מלא, או מסלול מהיר לדיף שנוגע ⛔ רק ברגיסטרים
5. הערת git       ⇒ רושמת `verify:` או `verify(fast):` — מה **באמת** רץ
```
🔴 **1 ו-2 קודמים ל-`SKIP_VERIFY`:** ‏`verify` שבור הוא סיבה לדלג על `verify`,
⛔ ולעולם לא סיבה לדרוס סוכן שבאמצע טיק או לדחוף ל-`main`.

**`npm run verify`** — הדבר שחייב להיות ירוק לפני כל דחיפת קוד:
```
typecheck · check:core · check:motion · check:text-floor · check:rules
· check:titles · npm test · build · check:mobile (1,519 בדיקות)
```

**`npm run loop:health`** — 23 בדיקות ממוספרות. ⛔ רק QA מריץ אותו כחלק מהשער.
⚠️ **שלושה מצבים, ⛔ ולא שניים:** עבר · נכשל · **«⛔ לא נמדד»**.
⛔ «לא נמדד» ⛔ אינו «עבר» — בודק שלא הצליח לרוץ ⛔ לא מצא דבר.

**`npm run walk:screens`** — פותח כל מסך בדפדפן אמיתי ברוחב טלפון, **מצלם**,
ומדווח HTTP · גלילה אופקית · שגיאות קונסול · אורך טקסט.
⇒ `check:mobile` ירוק אומר שהטענות עברו, ⛔ לא שמישהו ראה מסך.

## 13. שלוש עובדות שמסבירות הרבה

1. **כל טיק הוא סשן חדש.** ⛔ אין זיכרון. מה שלא נכתב לקובץ — ⛔ לא קרה.
2. **הרגיסטר ⛔ אינו המוצר.** 75% מקומיטי הלופ ⛔ לא נגעו בקוד מוצר.
3. **הארכיון עונה «מה עשינו», ⛔ ולא «מה קורה עכשיו»** (`RULES § 0.30`).
   תסמין שנמדד שוב הוא ממצא **חדש** עם מדידה טרייה — ⛔ לא החייאה של שורה סגורה.

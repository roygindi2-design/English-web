# /lib/core — הליבה הטהורה

הקוד כאן חייב לרוץ **כמות שהוא** בתוך React Native ביום שנמיר את האתר לאפליקציה.
לכן חלים עליו איסורים מוחלטים:

- ❌ `import React` / JSX
- ❌ `window`, `document`, `localStorage`, `sessionStorage`, `navigator`
- ❌ `fetch`, גישה לרשת, גישה לדאטהבייס
- ❌ `process.env`
- ✅ פונקציות טהורות בלבד: קלט → פלט, בלי תופעות לוואי

כל מה שהמודול צריך — מועבר אליו כפרמטר.
הבדיקה `npm run check:core` אוכפת את זה אוטומטית ורצה בכל בנייה.
